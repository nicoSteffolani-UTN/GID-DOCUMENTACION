# ADR-001: Frontend Angular con SSR

- **Estado:** Aceptado
- **Fecha:** 2026-05 (Instancia 2)
- **Autores:** Grupo G24

## Contexto

Portal provincial con stack alineado a sistemas existentes del Ministerio de Educación de Córdoba.

## Decisión

Usar **Angular con SSR** para el frontend.

## Consecuencias

- **Positivo:** Alineación con restricción provincial; ecosistema maduro para formularios complejos.
- **Negativo:** Curva de aprendizaje y configuración SSR más pesada que SPA simple.

## Referencias

- Instancia 2 §11 · Instancia 1 (stack provincial)
