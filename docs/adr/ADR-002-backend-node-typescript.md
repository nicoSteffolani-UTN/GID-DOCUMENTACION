# ADR-002: Backend Node.js con TypeScript

- **Estado:** Aceptado
- **Fecha:** 2026-05 (Instancia 2)

## Contexto

API del portal docente; coherencia de lenguaje con tooling moderno y restricciones provinciales.

## Decisión

**Node.js con TypeScript** en modo estricto.

## Consecuencias

- **Positivo:** Mismo ecosistema que lineamientos provinciales; tipado compartido con front.
- **Negativo:** Performance y tipos estrictos requieren disciplina en PRs.

- Instancia 2 §11–§12
